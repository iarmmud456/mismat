    Los tres tipos de sistemas

    El teorema de Rouché–Capelli compara el rango de la matriz de coeficientes A con el de la ampliada (A|B) y con el número de incógnitas n.

    • rg(A) = rg(A|B) = n: compatible determinado, una única solución.
    • rg(A) = rg(A|B) < n: compatible indeterminado, infinitas soluciones con n − rg parámetros.
    • rg(A) < rg(A|B): incompatible, no hay solución.

    Matriz inversa

    1. Escribe el sistema como A·X = B.
    2. Calcula Δ = |A|. Si Δ = 0, no hay inversa.
    3. Halla la matriz de cofactores, su traspuesta (adjunta) y A⁻¹ = (1/Δ)·Adj(A).
    4. X = A⁻¹·B. Comprueba sustituyendo.

    Solo sirve con matriz cuadrada y Δ ≠ 0. En los demás casos la calculadora pasa a Gauss.

    Método de Gauss

    1. Escribe la matriz ampliada (A|B).
    2. Con operaciones entre filas, haz ceros por encima y por debajo de cada pivote y deja pivotes iguales a 1.
    3. Cuenta los rangos y clasifica el sistema.
    4. Una fila 0 = c con c ≠ 0 indica que no hay solución. Las incógnitas sin pivote pasan a ser parámetros.

    Errores frecuentes

    • Olvidar el signo al hacer F₂ ← F₂ − k·F₁ con k negativo.
    • Operar solo con parte de la fila y no con el término independiente.
    • Aplicar la inversa sin comprobar antes que Δ ≠ 0.
    • Dar la solución de un sistema indeterminado sin indicar los parámetros.

    Ideas para clase

    • Proyecta un ejemplo y usa el modo clase para avanzar paso a paso.
    • Resuelve el mismo sistema con los dos métodos y compara.
    • Genera ejemplos de los tres tipos y pide que los clasifiquen antes de resolver.
